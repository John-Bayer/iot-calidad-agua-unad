# Base de datos

Este directorio contiene el script SQL utilizados para crear y configurar la base de datos del sistema IoT de monitoreo de calidad del agua, así como también los registros de las mediciones adquiridas por medio de la simulación del prototipo en Wokwi y su implementación física.

**Motor:** MySQL/MariaDB.

Las credenciales de conexión no se almacenarán en este repositorio.
