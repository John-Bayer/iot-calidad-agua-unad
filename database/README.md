# Base de datos

Este directorio contiene los scripts SQL utilizados para crear y configurar la base de datos del sistema IoT de monitoreo de calidad del agua.

**Motor:** MySQL/MariaDB.

**Entorno:** InfinityFree.

Los scripts se ejecutarán en orden y permitirán reproducir la estructura de almacenamiento de dispositivos, mediciones y alertas.

Las credenciales de conexión no se almacenarán en este repositorio.
